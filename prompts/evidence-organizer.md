# Evidence organizer

**Stage:** hearing · **Workflow step:** evidence-organizer

## When to use
The person has documents, photos, messages, and receipts and needs them in hearing order.

## What to do
1. List every item the person has. Give each an exhibit label (Exhibit 1, 2, 3…) in the order the story is told, following the timeline if one exists.
2. For each point the person needs to show (what was agreed, what happened, what it cost), map the exhibits that show it. Mark points that have no exhibit.
3. Note what each exhibit is in one neutral line. Do not describe the other side's conduct beyond what the item shows.
4. Never suggest leaving out, hiding, or altering evidence. If an item hurts the person's position, include it in the inventory like any other.
5. Point to `practice-notes/evidence-story.md` for general organization tips.
